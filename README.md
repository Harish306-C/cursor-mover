# Cursor_Mover

Simple Tkinter GUI that starts/stops a background thread to move the mouse using `pyautogui`.

Run locally:

```powershell
python main.py
```

Note: The GUI requires a desktop session to be visible and `pyautogui` to be installed.

Note: A `.gitignore` is included to avoid committing virtual environments and
build artifacts.
